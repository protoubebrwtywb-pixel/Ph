# صيدلية دعاء كاظم — كتالوج أدوية تجريبي

موقع عربي RTL متجاوب، مصمم للآيفون والجوال أولاً. يعرض **8 منتجات** مع وصف مختصر، السعر بالدينار العراقي، والتفاصيل في نافذة تفاعلية، **من دون شراء أو سلة**.

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح، أو ارفع محتويات المجلد إلى GitHub Pages. ميزات التثبيت والعمل دون إنترنت (PWA) تحتاج أن يُفتح الموقع عبر HTTPS أو `localhost`.

## النشر على GitHub Pages

1. أنشئ مستودعًا (Repository) عامًا جديدًا على GitHub، مثل `duaa-kadhim-pharmacy`.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع (`index.html`, `css`, `js`, `assets`...). لا ترفع المجلد الأب كطبقة إضافية.
3. انتقل إلى `Settings → Pages → Build and deployment`.
4. اختَر `Deploy from a branch` ثم `main` و`/(root)` واضغط `Save`.
5. يصبح العنوان عادةً `https://USERNAME.github.io/duaa-kadhim-pharmacy/`. إذا سميت المستودع `USERNAME.github.io` يصبح الموقع على `https://USERNAME.github.io/`.
6. من سفاري في الآيفون يمكنك فتح قائمة المشاركة ثم **إضافة إلى الشاشة الرئيسية** لتثبيته كتطبيق ويب.

## تعديل المنتجات والأسعار

افتح `js/app.js` ثم عدّل قائمة `PRODUCTS` في بداية الملف. الأسعار قيم رقمية بالدينار العراقي **من دون فواصل** (مثال: `price:3500`). بدّل الأسماء والأوصاف كما تريد.

## المزايا

- دعم عربي واتجاه RTL كامل.
- تصميم متجاوب للأجهزة الصغيرة والكمبيوتر.
- بحث فوري، تصنيفات، وترتيب حسب السعر أو الاسم.
- نافذة تفاصيل مستقلة لكل منتج، مع مشاركة الرابط.
- وضع فاتح/داكن مع حفظ التفضيل.
- وضع PWA للتثبيت على الشاشة الرئيسية، وتخزين الموقع للعرض دون إنترنت بعد فتحه أول مرة.
- تحسينات وصول: تنقل بلوحة المفاتيح، تسميات واضحة، واحترام خيار تقليل الحركة.
- دون مكتبات JavaScript خارجية أو خدمات مدفوعة.

> **تنويه:** هذا نموذج واجهة فقط؛ الأسعار افتراضية ولا تعكس الأسعار الحقيقية في الصيدليات. المحتوى معلومات وصفية عامة ولا يغني عن نصيحة الطبيب أو الصيدلي.
